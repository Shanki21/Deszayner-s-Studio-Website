# Font Files

Place the licensed webfont files here using these names:

- `PluvixLuxury.woff2` or `PluvixLuxury.woff`
- `AadamModernSerif.woff2` or `AadamModernSerif.woff`
- `AbiahSans.woff2` or `AbiahSans.woff`

The site is already wired with `@font-face` rules in `styles.css`.

Recommended pairing for this luxury monochrome website:

- Pluvix Luxury: brand/logo accent only
- Aadam Modern Serif: hero, section headings, quote, and card titles
- Abiah Sans: navigation, body copy, forms, and buttons
